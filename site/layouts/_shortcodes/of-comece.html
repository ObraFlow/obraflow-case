Comece rápido

Rode localmente com Node 20 — sem container, sem credencial:

git clone -b resolucao-obraflow https://github.com/Carolbalbs/obraflow-case.git
cd obraflow-case && npm install
cp .env.example .env
npx prisma migrate dev && npm run seed
npm run dev

Abra localhost:3000 e entre como Amanda — a sessão é de demonstração, sem senha. Veja o ADR 0005.

Primeiros passos ⇒

API que recusa fora da vez

Quem decide a ordem é o back-end. Aprovar uma etapa:

curl -X POST localhost:3000/api/pedidos/{id}/decisoes \
  -H 'Cookie: obraflow_sessao=cseedusuarioamanda0002' \
  -H 'Content-Type: application/json' \
  -d '{"tipo":"aprovar"}'

Fora da vez, a resposta é 409 NAO_E_SUA_VEZ; sem permissão, 403; sem faixa aplicável, 422.
