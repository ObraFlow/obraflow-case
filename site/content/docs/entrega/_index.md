## Processo de entrega

{{% steps %}}

### Fork

Faça **fork** de `https://github.com/ObraFlow/obraflow-case`.

### Pull Request

Abra um **Pull Request** para esse repositório até o prazo.

### Contato na descrição

**Na descrição do PR**, inclua **e-mail e telefone (WhatsApp)** para contato.

{{% /steps %}}

## O que o repositório deve conter

- [ ] código-fonte do **front-end** e do **back-end**;
- [ ] **dados de demonstração** e instruções para criá-los ou carregá-los;
- [ ] `README.md` completo (ver [checklist](readme));
- [ ] instruções claras para **instalar dependências, configurar o ambiente e iniciar a
      solução completa** (front-end, back-end e banco de dados, quando aplicável).
